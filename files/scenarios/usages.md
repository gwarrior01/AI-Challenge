# Где используется McpManager

Найди все места в проекте, где используется `McpManager` из `llm-core`: где его
создают, где подключают серверы, где вызывают инструменты. Сгруппируй по крейтам
(core, cli, tui, web, assistant, support, files…), для каждого места — `путь:строка`
и одной фразой, что там происходит. В конце — сколько всего мест и в каких крейтах.
Файлы не меняй.
