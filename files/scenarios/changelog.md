# CHANGELOG по истории git

Сгенерируй `CHANGELOG.md` в корне проекта по истории git: по разделу на каждый
день челленджа (ветки `day-N`, смерженные в main), от новых к старым. В разделе —
что появилось в этот день, по сообщениям коммитов и, где непонятно, по
документации в `docs/`. Формат — Keep a Changelog, на русском. Если файл уже
есть — обнови его, не теряя существующих записей.
