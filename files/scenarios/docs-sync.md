# Документация ассистента разработчика ↔ код

Проверь, совпадает ли таблица «Настройки» (переменные окружения) в
`docs/developer-assistant.md` с тем, какие переменные окружения на самом деле
читает код `code-assistant` (`assistant/src`). Обнови таблицу по коду: исправь
устаревшие имена, добавь недостающие переменные с их значениями по умолчанию,
убери те, которых в коде нет. Остальной текст документа не трогай. В отчёте
перечисли, что было не так.
