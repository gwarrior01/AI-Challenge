# Интеграции и API

## Готовые интеграции

Интеграции подключает администратор или владелец: «Настройки пространства → Интеграции». Доступны на всех тарифах.

- **Slack** — уведомления о задачах в канал и создание задачи из сообщения (меню сообщения → «Создать задачу в CloudDesk»).
- **Telegram** — личные уведомления через бота @CloudDeskBot: в профиле «Уведомления → Telegram → Подключить», затем нажать «Start» в боте.
- **Google Calendar** — задачи со сроками появляются в календаре; синхронизация в одну сторону, из CloudDesk в календарь, раз в 15 минут.
- **GitHub** — ссылка на задачу в коммите или pull request (`CD-123`) добавляет его в задачу, а слияние PR может закрыть задачу.

Если интеграция перестала работать, отключите и подключите её заново — чаще всего истёк доступ во внешнем сервисе.

## API

REST API доступен на тарифах Pro и Business. Токен создаётся в «Профиль → Токены API»; токен действует от имени создавшего его пользователя и с его правами. Ограничение — 100 запросов в минуту на токен, при превышении API отвечает кодом 429. Документация API — по адресу `/api/docs` в вашем пространстве.

## Вебхуки

На тарифе Business можно настроить вебхуки: «Настройки пространства → Интеграции → Вебхуки». CloudDesk отправляет POST-запрос на ваш адрес при событиях (задача создана, изменена, закрыта; комментарий добавлен). Неудачная доставка повторяется 3 раза с интервалом 5 минут.
