# О продукте CloudDesk

## Что такое CloudDesk

CloudDesk — облачный сервис для командной работы над проектами. В одном месте команда ведёт проекты и задачи, хранит документы и файлы, обсуждает работу в комментариях и смотрит отчёты о ходе проектов. Данные хранятся в облаке, устанавливать сервер не нужно.

## Из чего состоит

- **Рабочее пространство** — общее пространство команды или компании. У пространства один владелец и один тариф, в него приглашаются участники.
- **Проекты** — внутри пространства; у каждого проекта свои задачи, документы, доски и участники.
- **Задачи** — с исполнителем, сроком, приоритетом, чек-листом, файлами и комментариями.
- **Документы** — совместное редактирование текстов внутри проекта с историей версий.
- **Отчёты** — сводки по задачам, срокам и загрузке участников.
- **Интеграции** — Slack, Telegram, Google Calendar, GitHub и открытый API.

## Где работает

CloudDesk работает в браузере (последние версии Chrome, Firefox, Safari и Edge), в приложениях для Windows и macOS и в мобильных приложениях для iOS и Android. Данные синхронизируются между устройствами автоматически. В мобильных приложениях доступны задачи, комментарии, документы на просмотр и уведомления; отчёты и настройки пространства — только в браузере и настольных приложениях.

## Как начать работу

1. Зарегистрируйтесь по email или через Google-аккаунт — сразу создаётся рабочее пространство на тарифе Free.
2. Создайте первый проект: «Новый проект» → название → шаблон (пустой, Kanban, разработка, маркетинг).
3. Пригласите коллег: «Настройки пространства → Участники → Пригласить».
4. Добавьте задачи и назначьте исполнителей.

Для знакомства в каждом новом пространстве есть демо-проект «Добро пожаловать в CloudDesk», его можно удалить.
