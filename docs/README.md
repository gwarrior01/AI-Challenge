# Документация проекта

Здесь — документация для разработчика: как устроен проект, где что лежит, какие у него данные и API. Корневой [`README.md`](../README.md) описывает возможности для пользователя подробно и по дням; эта папка — короткий справочник по устройству кода.

Эту папку вместе с `README.md` читает **ассистент разработчика** — команда `/help <вопрос>` в TUI, веб-интерфейсе и CLI (см. [developer-assistant.md](developer-assistant.md)). Новый файл `.md` в `docs/` попадает в его индекс сам при следующем вопросе — ничего перезапускать не нужно.

| Файл | О чём |
|---|---|
| [architecture.md](architecture.md) | Крейты workspace, модули ядра `llm-core`, путь запроса агента, где что лежит |
| [data-schemas.md](data-schemas.md) | Схемы данных: SQLite-базы (`agents.db`, индекс RAG, `scheduler.db`), файлы конфигурации (`mcp.json`, профили, инварианты), конфигурация агента |
| [api.md](api.md) | HTTP API веб-интерфейса, инструменты собственных MCP-серверов, API шлюза `llm-gateway` |
| [development.md](development.md) | Сборка, тесты, запуск, переменные окружения, соглашения по коду, как добавить MCP-сервер |
| [developer-assistant.md](developer-assistant.md) | Ассистент разработчика: `/help`, RAG по документации, MCP-сервер git |
